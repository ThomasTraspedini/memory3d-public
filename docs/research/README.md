# Research records

Public research records preserve decision-relevant positive, negative, and inconclusive findings
without publishing private campaign machinery or raw model artifacts.

- [Retrieval research](retrieval.md) records bounded candidate ordering and rejected synthesis.
- [Epistemic-safety failure](epistemic-safety.md) records the failure that motivated the evidence
  envelope.

These records constrain claims. They are not benchmarks for unrelated hosts, models, or domains.
