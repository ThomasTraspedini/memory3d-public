# Provenance

This repository is a curated public lineage derived from a larger private research history. Public
commits are reconstructed, coherent engineering milestones; they are not the original private Git
ancestry, and the repositories share no copied Git objects, refs, branches, tags, or remotes.

Legacy code, internal task machinery, raw evaluation infrastructure, model artifacts, and unrelated
internal material were deliberately excluded. Omitted material is not implied to have never
existed. Private source hashes may appear in research records or ADRs as provenance references;
they identify private source evidence and do not create public ancestry or make that evidence
independently reproducible here.

Private task numbers retained in selected records are historical milestone labels, not instructions
or prerequisites for understanding the public API. Public package versions and commits are
independent of those labels.

The public repository preserves the implementation, deterministic tests, selected decisions,
negative findings, and lifecycle demo needed to review the released boundary. Start with the
[verification guide](verification-guide.md); treat it as an index to public evidence rather than as
evidence by itself.
